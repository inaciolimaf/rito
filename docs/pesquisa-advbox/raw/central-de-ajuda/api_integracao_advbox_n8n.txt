O que é a Integração ADVBOX com n8n
A integração entre ADVBOX e n8n permite que escritórios jurídicos criem automações poderosas conectando seu sistema de gestão jurídica com centenas de outras ferramentas e serviços. Através dos nodes personalizados 
n8n-nodes-advbox
, você pode automatizar tarefas repetitivas, sincronizar dados e criar fluxos de trabalho inteligentes.
O que é o n8n
O n8n é uma plataforma de automação de fluxo de trabalho de código aberto que permite conectar diferentes aplicações e serviços sem necessidade de programação complexa. Com uma interface visual intuitiva, você pode criar automações personalizadas que executam tarefas automaticamente baseadas em gatilhos e condições específicas.
Principais características do n8n:
Interface visual de arrastar e soltar
Mais de 400 integrações nativas
Código aberto e auto-hospedável
Suporte a JavaScript para lógicas complexas
Execução de fluxos baseada em eventos
Instalação dos Nodes ADVBOX
Os nodes personalizados da ADVBOX estão disponíveis através do sistema de Community Nodes do n8n, facilitando a instalação e atualização.
Como instalar:
1
Acesse as Configurações do n8n
No seu painel administrativo do n8n, vá até "Settings" > "Community Nodes".
2
Instale o Pacote
Digite o nome do pacote: 
n8n-nodes-advbox
Clique em "Install" e aguarde a conclusão.
3
Reinicie o n8n
Após a instalação, reinicie sua instância do n8n para ativar os novos nodes.
4
Configure a Autenticação
Use seu token da API ADVBOX para autenticar os nodes.
