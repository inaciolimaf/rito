Neste artigo, você vai aprender como gerar recibos padrão,controlar visualização de registro por página e informações sobre os lançamentos via Asaas, facilitando a documentação de valores recebidos, no seu escritório jurídico.
Gerar Recibo
A ADVBOX permite gerar um recibo padrão para qualquer receita, mesmo sem pagamento confirmado.
Como gerar:
1
Localize o lançamento
Na listagem do 
Menu Financeiro
, localize o lançamento de receita.
2
Clique no ícone de impressão
Clique no 
ícone de documento/impressão
, na linha do lançamento.
3
Recibo gerado
Um PDF será gerado automaticamente e aberto em uma nova aba.
Conteúdo do recibo:
Título "RECIBO" com valor em destaque
Texto padrão: "Recebi(emos) de [nome], inscrito(a) no CPF/CNPJ [número], a importância de R$ [valor], referente a [descrição]."
Data de geração
Nome, endereço, telefone e e-mail do escritório
Logo do escritório (se cadastrado)
Importante:
O recibo é gerado mesmo que a receita ainda não tenha sido paga
O modelo é fixo — não é possível editar textos ou campos na hora da emissão
Dados como CPF/CNPJ precisam estar preenchidos no cadastro para aparecer completos
O recibo serve como declaração interna — não substitui documento fiscal oficial
Dica:
 Certifique-se de que os dados do cliente e do escritório estejam completos no cadastro para que o recibo seja gerado com todas as informações necessárias.
Lançamentos com cobrança via Asaas
1
Baixa automática
A baixa é feita 
automaticamente
 após o pagamento ser compensado no Asaas.
2
Alerta de sincronização
Se tentar preencher a data manualmente, o sistema exibirá o alerta: 
"Esta cobrança está sincronizada com o Asaas. Alterar o pagamento manualmente irá interromper a compensação automática. Deseja continuar?"
3
Opções do usuário
O usuário poderá 
confirmar ou cancelar
 a ação.
Dica:
 Mantenha a sincronização automática sempre que possível para evitar divergências entre os sistemas ADVBOX e Asaas.
Como controlar a visualização de Registros por página
1
Escolha a quantidade de registros
Na parte inferior da lista de lançamentos, é possível escolher quantos registros exibir por página: 
50, 100, 200, 500, até 5.000
.
2
Visualize a quantidade atual
O sistema também mostra a quantidade de registros atuais na página. Exemplo: 
"1–30 de 30"
.
Navegação entre páginas
1
Use os ícones de navegação
Use os ícones para navegar entre as páginas:
<<
 Primeira página
<
 Página anterior
>
 Próxima página
>>
 Última página
Importante lembrar:
A 
exportação considera apenas a página atual
Para exportar volumes maiores, 
troque de página
 e repita a exportação
Dica: 
divida por período, categoria ou conta
 para facilitar quando houver muitos lançamentos
Dica:
 Para melhor performance do sistema, use filtros específicos ao trabalhar com grandes volumes de lançamentos financeiros.
